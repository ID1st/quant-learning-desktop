# 第四阶段 - 图表工作台模块

## 当前模块范围

本模块完成桌面端图表工作台的第一版可交互外壳。

已实现：

- TradingView 风格的顶部标的栏、周期切换和指标开关。
- 左侧画线工具栏占位。
- 右侧多市场观察列表。
- 中央 K 线图、成交量、平滑均线、十字光标。
- 买入/卖出信号箭头展示。
- 底部策略面板、订单信息、日志窗口占位。
- 标的切换后重新生成本地模拟行情。
- 周期切换后更新图表上下文。
- 均线和信号显示开关。

## 当前占位规则

当前阶段不接入真实行情，也不接入真实策略执行。

- K 线数据由 `packages/chart/src/index.tsx` 根据标的生成确定性模拟数据。
- 买卖信号为固定模拟点位，仅用于验证图表标记能力。
- 均线为本地 9 周期简单移动平均线。
- 十字光标基于 SVG 鼠标位置计算。

后续接入真实行情时，应保留 `ChartViewport` 的上下文接口，将数据源替换为行情缓存或实时行情流。

## 非本模块范围

本模块不实现：

- TradingView Charting Library 或 Lightweight Charts 的正式接入。
- 真实美股、港股、A股行情同步。
- 多图表窗口拆分。
- 画线工具的持久化。
- 策略回测和实盘执行。
- 订单下发。


```powershell

```

- 图表工作台可打开。
- K 线、成交量、均线、买卖箭头正常渲染。
- 周期切换可用。
- 观察列表标的切换可用。
- 信号开关可控制箭头显示。
- 可见中文无乱码。
