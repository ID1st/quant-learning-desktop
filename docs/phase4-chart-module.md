# 第四阶段 - 图表工作台模块

## 当前状态

超级图表工作台已经进入 Phase 4 的能力补齐阶段。当前重点不再是静态原型，而是围绕真实缓存行情、策略图层、行情状态和 TradingView-like 工作台体验做迭代。

## 已完成

- 图表工作台使用真实缓存行情，不再在生产工作台显示原型 K 线。
- 支持 `realtime`、`1d`、`1w` 三个核心周期。
- `realtime` 历史通过 provider-neutral intraday gateway 加载，并写入 `realtime` 缓存。
- `1d` 图表可合并最新实时快照形成当日 K 线。
- 图表支持缩放、平移、十字光标、当前价线、价格标签、成交量、网格、均线和视图重置。
- 右侧价格轴支持上下拖拽调整纵向比例。
- 横轴显示北京时间。
- 策略图层通过声明式 render elements 渲染，不直接调用图表内部实现。
- UTORB 和 Trend Targets 可基于真实缓存 K 线输出信号、日志、指标和图层元素。
- 策略参数通过配置弹窗编辑，不再长期占用主图空间。
- 第一轮 UI/显示优化已完成：图表优先布局、右侧观察列表折叠、底部紧凑 dock、图层/信号/日志 tab、行情状态条。
- 横向拖动图表时，价格轴和成交量轴保持当前显示比例，不再因为可视窗口变化而自动重算纵向比例。
- 浏览器验证覆盖 1366x768、1440x900、1920x1080，未发现页面级纵向滚动、按钮溢出或空白黑屏。

## 当前布局规则

- 主图表是默认视觉中心。
- 顶部工具栏保持紧凑，仅放高频操作。
- 右侧观察列表默认展开，可折叠为窄栏。
- 底部面板固定为紧凑 dock，通过 tab 切换图层、信号和日志。
- 策略详细参数只在用户点击配置入口后打开。
- 策略目标线和区域不参与自动价格轴缩放，避免压扁主价格走势。
- 横向拖动只移动时间窗口，不触发价格线条和成交量区域的自动缩放；主动缩放或重置视图时才重新计算显示比例。

## 下一步

1. Provider diagnostics timeline：展示当前数据源、fallback、rate-limit、延迟、数据 gap 和最近更新时间。
2. Indicator layer controls：扩展均线之外的指标层控制。
3. Drawing tool foundation：补充画线工具选择、取消、重置和命令模型占位。
4. Layer ordering controls：在策略、指标、画线图层统一后加入显式层级调整。
5. Browser smoke verification：每个图表 UI 切片继续覆盖 1366x768、1440x900、1920x1080。

## 非本阶段范围

- 不替换图表底层库。
- 不实现完整 TradingView Charting Library。
- 不实现真实交易下单。
- 不实现完整回测报告。
- 不实现插件系统和学习系统。
- 不实现画线对象持久化。
