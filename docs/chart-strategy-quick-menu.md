# 超级图表策略快捷菜单规格

## 目标

将超级图表顶部工具栏的“均线”按钮替换为“策略”按钮。点击后展示当前图表运行时可用的全部策略，并允许用户快速启用策略或打开该策略的参数配置。

## 技术与位置

- React 19、TypeScript、Zustand、lucide-react。
- 页面集成：`apps/desktop/src/pages/ChartWorkspacePage.tsx`。
- 交互模型：`apps/desktop/src/features/chartWorkspace/strategyQuickMenu.ts`。
- 样式：`apps/desktop/src/styles.css`。
- 测试：`apps/desktop/tests/strategy-quick-menu.test.ts`。

## 交互

- “策略”按钮具有下拉状态，显示已启用策略数量。
- 下拉列表顺序与当前策略注册表一致，覆盖内置、用户和插件策略。
- 每个策略提供“打开”按钮；开启时同步恢复该策略图层显示。
- 每个策略提供“参数”按钮，复用已有参数配置弹窗。
- 点击菜单外、按 Escape、或打开参数弹窗时关闭下拉菜单。
- 保留现有“策略图层”总开关。

## 边界

- 不改变策略计算、注册、插件加载或参数持久化机制。
- 不增加依赖。
- 不改变原“指标”按钮及其均线指标设置能力。
- 保留工作树中现有的 MLPT 和行情数据改动。

## 验收

- 菜单展示当前全部可用策略及其启用状态。
- “打开”立即更新策略状态并持久化。
- “参数”打开对应策略的现有配置弹窗。
- 按钮和菜单具备可访问名称、展开状态与键盘关闭行为。
- 桌面测试、类型检查、构建和浏览器交互验证通过。
