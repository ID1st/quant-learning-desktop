# 第四阶段 - 登录模块

## 当前模块范围

本模块完成桌面端登录与注册流程的第一版前端闭环。

已实现：

- 登录/注册页面。
- 邮箱、密码、确认密码、邀请码、邮箱验证码字段。
- 基础表单校验。
- 邮箱验证码发送入口。
- 注册邀请码校验入口。
- 登录/注册成功后的本地会话状态。
- 本地会话写入 `localStorage`。
- 退出登录。
- 登录成功后进入接口配置页，引导后续绑定长桥 API。

## 当前占位规则

由于云端认证、邀请码和邮箱验证码接口尚未接入，当前使用本地占位服务：

- 邀请码：`QUANT2026`
- 邮箱验证码：`123456`
- 密码要求：至少 8 位

这些规则只用于第四阶段登录模块的前端流程验证。后续接入云端认证服务后，应替换 `apps/desktop/src/features/auth/authService.ts` 中的占位实现。

## 非本模块范围

本模块不实现：

- 云端用户数据库。
- 真实邀请码联网验证。
- 真实邮箱验证码发送。
- 密码哈希与服务端会话。
- 长桥 API 绑定。
- 行情同步。
- 策略执行。
