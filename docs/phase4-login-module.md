# 第四阶段 - 登录模块（历史记录）

> 本文记录早期前端占位阶段，已被
> `docs/authentication-architecture.md` 中的云端认证方案取代。
> 当前生产代码不再接受固定邀请码或固定邮箱验证码。

## 当时的模块范围

本模块曾用于完成桌面端登录与注册流程的第一版前端闭环。

已实现：

- 登录/注册页面。
- 邮箱、密码、确认密码、邀请码、邮箱验证码字段。
- 基础表单校验。
- 邮箱验证码发送入口。
- 注册邀请码校验入口。
- 登录/注册成功后的本地会话状态。
- 当时的本地会话写入 `localStorage`。
- 退出登录。
- 登录成功后进入接口配置页，引导后续绑定长桥 API。

## 已移除的占位规则

早期原型曾使用固定邀请码和固定邮箱验证码。该实现现已删除：

- 邀请码改为云端摘要保存、事务核销和批量管理。
- 邮箱验证码改为 SMTP outbox 投递、10 分钟有效和最多 5 次尝试。
- 密码改为 8–64 位、无空格 ASCII，并同时要求大小写字母、数字和特殊符号。
- 访问令牌只保存在 Electron 主进程内存，刷新令牌和离线租约使用
  `safeStorage` 加密，不再写入 Renderer 或 `localStorage`。

## 后续实现

以下能力已在当前认证改造中实现：

- Fastify 认证 API、PostgreSQL 数据模型和 Argon2id 密码摘要。
- 首次邀请码验证、资格续期、到期阻断和批量邀请码 CLI。
- Electron 主进程认证边界、离线租约和受保护路由。
- 注册、登录、忘记密码、邀请码、到期续期和设置页资格信息。
