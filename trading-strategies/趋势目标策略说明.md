# Trend Targets — 趋势目标策略说明

> 本文档详细说明 Trend Targets [AlgoAlpha] 策略的工作原理、核心逻辑及使用方法，帮助用户理解策略信号并正确配置参数。

---

## 1. 策略概述

**Trend Targets** 是一个基于 SuperTrend 指标构建的趋势跟踪策略，通过对 SuperTrend 输出进行双层平滑处理，生成一条稳定的趋势基准线，并在此基础上识别趋势转变与价格拒绝信号。同时，策略内置了基于 ATR 的动态止损与三级止盈体系，在检测到趋势信号时自动标注入场、止损和目标价位。

### 适用场景

- 有明显趋势行情的市场（单边上涨或下跌）
- 中长线波段交易
- 日线及以上的时间周期

---

## 2. 核心逻辑

### 2.1 趋势基准线的生成

策略的核心是一条平滑的趋势线（`tL`），生成流程如下：

```
SuperTrend 计算
      ↓
取上轨与下轨的均值 (math.avg)
      ↓
加权移动平均平滑 (WMA)
      ↓
指数移动平均再平滑 (EMA)
      ↓
趋势基准线 (tL)
```

与直接使用原始 SuperTrend 相比，双层平滑后的趋势线大幅减少了虚假穿越信号，使趋势判断更加稳定。

### 2.2 趋势方向判断

策略通过比较当前 K 线的趋势线与前一 K 线的趋势线来判断方向：

| 信号 | 条件 | 趋势方向 |
|------|------|----------|
| 多头趋势转变 | `tL` 上穿前一值（向上拐头） | 多头趋势（趋势 = 1） |
| 空头趋势转变 | `tL` 下穿前一值（向下拐头） | 空头趋势（趋势 = -1） |

趋势方向确定后，K 线会相应地染成多头颜色或空头颜色，基准线颜色也随之改变。

### 2.3 拒绝信号

当价格回踩趋势线但未能有效突破时，策略识别为"拒绝信号"，意味着趋势支撑/压力有效，趋势可能延续。

拒绝信号的判定流程：

1. **条件**：当前趋势为多头时，K 线的最高价高于趋势线且最低价低于趋势线（即 K 线穿过趋势线但收盘未远离）；空头同理。
2. **计数**：满足条件的连续 K 线会累加计数（`rejcount`）。
3. **触发**：当连续计数超过设定的**确认次数**时，在趋势线位置标注信号图标。
4. **重置**：趋势反转或价格脱离趋势线时，计数清零。

| 信号 | 图标 | 含义 |
|------|------|------|
| 多头拒绝信号 | ▲ | 多头趋势中价格回踩支撑有效，趋势延续概率大 |
| 空头拒绝信号 | ▼ | 空头趋势中价格反弹压力有效，趋势延续概率大 |

### 2.4 入场、止损与止盈

当趋势方向由空转多（做多信号）或由多转空（做空信号）时，策略会自动绘制入场线及风险控制价位。

#### 多头入场

| 要素 | 计算方式 |
|------|----------|
| **入场价** | 信号触发时的收盘价 |
| **止损价** | 当前最低价 - ATR × 止损 ATR 倍数 |
| **目标1** | 入场价 + (入场价 - 止损价) × 目标1 倍数 |
| **目标2** | 入场价 + (入场价 - 止损价) × 目标2 倍数 |
| **目标3** | 入场价 + (入场价 - 止损价) × 目标3 倍数 |

#### 空头入场

| 要素 | 计算方式 |
|------|----------|
| **入场价** | 信号触发时的收盘价 |
| **止损价** | 当前最高价 + ATR × 止损 ATR 倍数 |
| **目标1** | 入场价 - (止损价 - 入场价) × 目标1 倍数 |
| **目标2** | 入场价 - (止损价 - 入场价) × 目标2 倍数 |
| **目标3** | 入场价 - (止损价 - 入场价) × 目标3 倍数 |

> **注意**：止损与目标的距离完全由 ATR（平均真实波幅）动态决定，因此会根据市场波动率自动调整。市场波动大时止损和目标都会相应扩大，反之亦然。

## 3. 参数详解

### 3.1 趋势设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **Supertrend 因子** | 12 | 决定 SuperTrend 带宽度的 ATR 倍数。值越大，带宽越宽，信号越少。建议在 7-15 之间调整。 |
| **Supertrend ATR 周期** | 90 | 计算 ATR 所用的 K 线数量。值越大，SuperTrend 带越平滑，对短期波动的反应越不灵敏。建议在 50-150 之间调整。 |
| **WMA 长度** | 40 | 加权移动平均的窗口长度。值越大，趋势线越平滑。建议在 20-60 之间调整。 |
| **EMA 长度** | 14 | 指数移动平均的窗口长度。控制趋势线的最终平滑度。建议在 10-30 之间调整。 |

### 3.2 拒绝信号设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **确认次数** | 3 | 触发拒绝信号所需的最少连续盘整 K 线数。值越大，信号越可靠，但可能出现滞后。建议 2-5。 |

### 3.3 目标设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **显示止盈水平** | 开启 | 切换图表上止盈目标线的显示。 |
| **波动率 (ATR) 周期** | 14 | 计算 ATR 的周期数，用于确定止损与止盈的距离。建议 7-21。 |
| **止损 ATR 倍数** | 5 | 止损距入场价的 ATR 倍数。值越大，止损越宽，容错率越高但盈亏比降低。建议 3-8。 |
| **目标1 倍数** | 0.5 | 第一止盈目标相对于止损距离的倍数。建议 0.5-1.0。 |
| **目标2 倍数** | 1.0 | 第二止盈目标相对于止损距离的倍数。建议 1.0-2.0。 |
| **目标3 倍数** | 1.5 | 第三止盈目标相对于止损距离的倍数。建议 1.5-3.0。 |

### 3.4 外观设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **多头颜色** | #00ffbb（青色） | 多头趋势时使用的颜色 |
| **空头颜色** | #ff1100（红色） | 空头趋势时使用的颜色 |

## 4. 图表信号速查

### 主图信号

| 图表元素 | 说明 |
|----------|------|
| **彩色 K 线** | K 线颜色随趋势方向变化（多头/空头色） |
| **趋势基准线** | 平滑后的趋势线，颜色随趋势变化 |
| **▲ 下方图标** | 多头拒绝信号，趋势支撑有效 |
| **▼ 上方图标** | 空头拒绝信号，趋势压力有效 |
| **带标签上箭头** | 多头趋势转变信号（趋势由空转多） |
| **带标签下箭头** | 空头趋势转变信号（趋势由多转空） |
| **入场线 + 标签** | 显示入场价位 |
| **红色止损线 + 标签** | 显示止损价位 |
| **绿色目标线 + 标签** | 分别显示目标1、目标2、目标3价位 |

### 警报信号

策略内置了以下警报条件，可在 TradingView 的警报设置中使用：

| 警报名称 | 触发条件 |
|----------|----------|
| 趋势转变：多头 | 价格上穿止损线 |
| 趋势转变：空头 | 价格下穿止损线 |
| 拒绝信号：空头 | 价格上探止损线后回落 |
| 拒绝信号：多头 | 价格下探止损线后回升 |
| 目标1/2/3 触及 | 价格分别触及三个目标价位 |

## 5. 使用建议

### 参数调优方向

- **减少信号频率**：增大 Supertrend 因子和 ATR 周期，同时增大确认次数。
- **增加灵敏度**：减小 Supertrend 因子和 ATR 周期，同时减少 WMA 和 EMA 长度。
- **扩大止损范围**：增大止损 ATR 倍数，适用于高波动市场。
- **提高盈亏比**：适当增大目标2和目标3的倍数。

### 注意事项

1. **趋势市优于震荡市**：该策略本质是趋势跟踪，在盘整震荡行情中可能产生连续假信号。
2. **参数需适配品种**：不同交易品种（股票、加密货币、外汇）波动特性不同，建议先回测再实盘。
3. **止损是风控核心**：虽然策略内置了止损，但极端行情下仍需关注是否出现跳空等超出止损范围的情况。
4. **结合其他分析**：建议将策略信号与关键支撑阻力位、成交量等结合判断，提高胜率。
